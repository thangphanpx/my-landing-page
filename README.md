# My Landing Page

This is a [Next.js](https://nextjs.org) project created from a Stitch design.

## Features
- Modern Neon Aesthetics
- Responsive Layout
- Next.js 16 + Tailwind CSS 4
- Material Symbols Outlined
- Google Fonts (Manrope, Inter, Space Grotesk)

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```
